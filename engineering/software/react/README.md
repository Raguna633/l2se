# React & TypeScript Frontend Engineering

Pusat pembelajaran frontend modern menggunakan **React**, **TypeScript**, dan **Vite** untuk membangun fondasi UI yang kokoh, modular, dan terprediksi tanpa ketergantungan pada meta-framework.

---

## 1. Fokus Pembelajaran
* **Mental Model React Modern**: Unidirectional data flow, kemurnian komponen, state sebagai snapshot.
* **TypeScript Strictness**: Type safety tanpa `any`, generic components, schema validation (seperti Zod).
* **State Management**: Local state (`useState`, `useReducer`), shared client state (seperti Zustand), server state caching (seperti TanStack Query).
* **Routing & Form**: Client-side routing (seperti React Router), pengelolaan form (seperti React Hook Form).
